# FAQ

**Why simulation instead of hardware?**
Lower cost, faster iteration, and validated public data (Kara One) removes
hardware variability while the decoding approach is proven out.

**Why start with SVM instead of deep learning?**
Establishes an interpretable baseline before adding model complexity.

**Why "thinking" epochs specifically?**
That's the imagined-speech state — the core object of study, as opposed to
resting, hearing the stimulus, or actually speaking.
