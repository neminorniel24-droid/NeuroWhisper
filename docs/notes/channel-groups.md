# EEG Channel Groups (10-20 system, approximate regions)

- Frontal: FP1, FPZ, FP2, AF3, AF4, F7, F5, F3, F1, FZ, F2, F4, F6, F8
- Central: FC*, C*, CZ
- Temporal: T7, T8, TP7, TP8
- Parietal: CP*, P*, PZ
- Occipital: PO*, O1, O2, OZ, CB1, CB2

Speech-relevant regions of interest: frontal (Broca's-adjacent) and
temporal (Wernicke's-adjacent) channels.
